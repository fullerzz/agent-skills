## Selective pstack orchestration cleanup {#pstack-orchestration-cleanup}

Reviewed the October 14 pstack orchestration cleanup from [PR #613](https://github.com/cursor/plugins/pull/613), merge [ce649c03](https://github.com/cursor/plugins/commit/ce649c03ac3b75b6ae80cbd15b7e2c536caedb5a), manifest still `0.15.23`. Three changes are adopted, each as one layer of a stacked PR series with its own paragraph below. Excluded: per-spawn effort and fast-mode selection, which conflicts with the local rule that native delegation inherits the host's configured model unless an override is requested; Cursor `grok`/`composer` model-family fallbacks; Origin forge support, including the worktree audit's Origin PR column, since `gh` already reports draft PRs as `OPEN` and the audit holds them; and wording fixes to text z-mode never carried.

**Owner-approval gate.** A completed `Code Review Gate` check run with an `ACTION_REQUIRED` conclusion now maps to the owner-approval gate on both the rollup and fast-check read paths, so the watcher neither fails on it nor waits on a human. Other checks with that conclusion still fail and keep their reported state. Because GitHub then reports the head rollup as `FAILURE` and the PR as `BLOCKED`, that aggregate refusal is also excused while such a gate is present; a pending gate does not excuse it. Ruff cleanup on this layer moves `hooks/xray.py` to `datetime.UTC`, raising the session hooks' Python floor from 3.10 to 3.11; README and the setup guide state it. Native manifests advance to `0.9.0` as a MINOR release because that changes the hook runtime contract.

**Frontier without Graphite.** `orch frontier set` no longer reads Graphite metadata. It asks `gh` for the repository's default branch as trunk, walks the PR base chain from the checkout's current branch down to trunk, then up through child PRs, and takes head SHAs from local `refs/heads` branches. A merged parent that its child still targets stays in the chain, and so does a child merged into its parent's branch; a reused branch resolves to its open PR, else its most recently created one. A head that targeted a branch counts as its child only if that head's current PR, from its full history, still targets it. A closed PR with an open or merged descendant, reached walking up (even through further closed PRs or beside an open sibling) or walking down, fails rather than leaving an orphaned chain; descendants are judged by their current PRs too. Fork PRs that reuse a stack branch name are ignored, `GH_REPO` is cleared so `gh` reads the checkout's repository, and each query asks for up to 1000 rows. On trunk the chain is empty. Elsewhere, a branch with no PR, more than one live child, a base loop, or a missing local branch fails instead of guessing. Upstream's `--forge origin` option is excluded with the rest of Origin support. The orchestrate playbook and playbook reference drop the Graphite prerequisite. Native manifests advance to `0.9.1` as a compatible fix.

**Shipping safety.** Shipping pins every force-push lease to the SHA last pushed or taken over and stops on an unknown push. Right before a merge it checks whether trunk's changes can affect the patch: untested code that would land forces a rebase, a changed caller or dependency runs the patch's checks on the merge result, and a third rebase after merge prep is held and reported. After a parent merges, any child is retargeted to trunk and only the child's own commits, counted from the parent commit recorded beneath them when the link was created or rebased rather than the parent's possibly rewritten final head, only when the landing authority covers the child, and only when that range has no merge commits, move onto the merge result before the patch re-check. Autopilot-full runs full independent review once at the code-ready head and repeats it only for new behavior, a redesign, or a large new diff; a rebase, conflict resolution, or minor fix gets one verifier. Autopilot-stack hands a link to the coordinator once its owner stops writing; only the coordinator then rebases or retargets it, and pushes need publication authority. Upstream's longer procedural rewrites of these playbooks, Cursor cloud-agent and `/loop` mechanics, and forge-specific merge commands are excluded; the local playbooks keep their shorter shape and explicit merge authority.
