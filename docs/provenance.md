# Upstream provenance

zstack, Zach's updated skillset, adapts Lauren Tan's [pstack](https://github.com/cursor/plugins/tree/main/pstack), copied from the Cursor plugins repository. The copied manifest declared version `0.15.5`. The exact copied commit was not recorded and has not been established. The MIT license and original copyright are retained in [LICENSE](../LICENSE).

The port keeps the portable engineering principles, reference prompts, decision logger, orchestration bookkeeping, and GitHub PR watcher. Workflow instructions now target Codex and Claude Code with native agents and local skill discovery.

The Cursor plugin manifest, branding assets, `make-bot-ui`, and dormant `automations/benny` pack are retired. The latter two require Cursor routines, secret cards, webhooks, or an automation runtime unavailable in this library. Recover their original sources from upstream if a replacement runtime becomes a concrete project. They are not installed or advertised as working here.

The native Codex plugin packages shared skills and a session hook through a local marketplace. The Claude Code plugin loads the same skills, hook, and agent roles in place through its own local marketplace. Public marketplace publication and a replacement agent daemon remain outside this release.

The Herdr integration is zstack-specific coordination guidance based on Herdr's [agent guide](https://herdr.dev/agent-guide.md), [concepts](https://herdr.dev/docs/concepts/), [working guide](https://herdr.dev/docs/how-to-work/), [automation documentation](https://herdr.dev/docs/agent-automation/), and [upstream operational skill](https://raw.githubusercontent.com/herdrdev/herdr/master/skills/herdr/SKILL.md), reviewed 2026-10-04. It references upstream operations rather than vendoring that skill. Explicit Herdr execution applies across existing playbooks; launching a requested CLI does not establish cross-provider consensus or inherited host configuration.

The ketchup skill was initially adapted from pstack 0.15.17, commit [978ca6e9](https://github.com/cursor/plugins/commit/978ca6e9c0e012047cd5058b8e829240336e704e), and selectively updated with 0.15.18's visual guidance from [PR #570](https://github.com/cursor/plugins/pull/570), commit [ea32d956](https://github.com/cursor/plugins/commit/ea32d9562a1c9f077d7cdd3be53d07383eb18866), reviewed 2026-10-12. It retains current-conversation catch-up, read-only inspection, earlier unresolved decisions, and option/recommendation summaries. The port adds explicit-only Codex policy, scoped native history and status readers for the supported hosts, current-head CI checks, and disclosed access gaps. Plain wording is self-contained rather than invoking bro's restatement workflow. Before/after and option comparisons use existing evidence; missing captures, unknown numbers, and rendering gaps are disclosed. The stricter chat-only boundary excludes file writes, new captures, app/job launches, and generated screen images. The retained MIT license and Lauren Tan copyright cover the adaptation; this is not a full upstream update.

Ketchup's bundled decision-visual reference adapts HumanLayer's [show-me implementation](https://github.com/humanlayer/skills/blob/653b6411c1f70c275a18e37673b042ff99f67ceb/plugins/show-me/skills/show-me/SKILL.md) at commit `653b6411c1f70c275a18e37673b042ff99f67ceb` (show-me plugin 1.0.1), inspected 2026-10-12. It adopts the smallest-useful-view approach, adjacent concise explanation, pseudocode, call/component/file trees, Mermaid, and diffs. It omits standalone HTML creation and the macOS `open` command to preserve ketchup's cross-host read-only boundary. No HumanLayer plugin is installed or required, and no upstream scripts were executed. The full [HumanLayer MIT notice](../skills/ketchup/references/HUMANLAYER-LICENSE.txt), including Copyright (c) 2026 HumanLayer, ships beside the adapted reference in linked and packaged skills and in the documentation site's notices.

The personal naming migration uses `zstack`, `z-mode`, `setup-zstack`, and `z-agent`. Upstream names and URLs remain in attribution and historical baseline records.

The benchmark-checklist and principle-explain-the-number skills were adapted from pstack 0.15.6, commit [23e4138](https://github.com/cursor/plugins/commit/23e4138daa01c42d4969f7a5465f82704e64f798). Their routing targets z-mode, preserves explicit invocation on both hosts, and uses portable host checks. This is a selective port, not a full update to that release.

The same commit supplies the fresh-agent lifecycle policy, adapted to native host limits and exclusive write ownership. Reuse remains available for costly agent-held state.

Its PR workflow updates are also adapted: built-in tools take precedence for supported operations, descriptions use concise section headings, and stack bases and readiness are read back. Repository templates, requested draft status, and publication authority still govern the workflow.

The create-verification-skill readiness fixes are selectively adapted from [PR #573](https://github.com/cursor/plugins/pull/573), head commit [8dd98e9](https://github.com/cursor/plugins/commit/8dd98e90937149ca1b8dba7103d45dce5003676d), reviewed 2026-10-12. Launch must finish migrations and seed data from an empty data directory before the app is usable; missing seed prerequisites fail the journey without weakening it; setup supplied only by a stand-in stays unverified on the real target. The port retains native project paths, explicit invocation, helper portability, and cleanup that preserves evidence. All three native manifests advance to `0.6.1` under the local compatible-fix policy. The retained MIT license and Lauren Tan copyright cover the adaptation; no other upstream changes are included.

The correct skill is adapted from pstack 0.15.7, commit [9511e603](https://github.com/cursor/plugins/commit/9511e60321f7e533a187d62854a3d53a53752874). It preserves repeated-mistake classification, the architecture/types/lint/tests/docs ordering, historical failure proofs, and the rule-to-enforcement table. The port adds scoped native history, explicit-only metadata for both hosts, isolated reproductions, and observed-versus-configured CI reporting. Upstream's automatic commits and future-correction trigger are replaced by task-specific authority and invocation scope. This is a selective skill port; the upstream version bump is not applied to zstack. The retained MIT license covers the adaptation.

The prompting recipes and usage guidance are selectively adapted from pstack 0.15.12, commit [807c0310](https://github.com/cursor/plugins/commit/807c031086fcf71c88c863b4a4e6938b6785c58f), and 0.15.13, commit [2cbf5850](https://github.com/cursor/plugins/commit/2cbf58508f40de470d7490b55c51d71241928fa2). The port covers prototypes for unresolved questions, planning, benchmark validation, inspectable verification, repeated-mistake prevention, cost controls, and trust before unattended work. Examples use native Claude Code and Codex invocation and retain task-specific authority. The help skill, Cursor Projects, cloud-agent instructions, and Benny automation pack are excluded; native scheduling remains available only when verified and requested. No upstream version bump or invocation-policy change is applied. The retained MIT license covers this documentation adaptation.
