# Recipes and limits

- `/how trace argument parsing; read-only`.
- `/interrogate this diff; findings only`.
- `/swarm check these three packages; one owned report per package`.
- `/poteto-mode fix duplicate output; reproduce first; keep changes local`.
- `/poteto-mode pause; record the exact resume action`.

Use dollar-prefixed skill names in Codex. Avoid overlapping writers, stale head receipts, unscoped history mining, and assuming a started agent completed. Scripts use absolute paths from the real installed skill; Git helpers inspect the target project. Retired automation sources are documented in [provenance](../provenance.md).
