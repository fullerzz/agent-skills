# Use principles when they change a decision

The [router's principle index](../../skills/poteto-mode/SKILL.md#principles) lists all 23 leaves. Read the relevant leaf instead of reciting every principle for each task.

For example, separate-before-serializing-shared-state favors owned outputs; fix-root-causes traces the actual mechanism; prove-it-works requires real evidence. None expands scope, overrides a read-only request, or authorizes publication.
