# Design and review

[architect](../../skills/architect/SKILL.md) starts with caller usage and types. A design request stops at a design unless implementation is already requested. Contested shapes can use [arena](../../skills/arena/SKILL.md) for independent candidates and synthesis.

[swarm](../../skills/swarm/SKILL.md) partitions coverage; [interrogate](../../skills/interrogate/SKILL.md) returns adversarial findings without edits. These use bounded native agents and report actual identities. Multiple runs may share one model; cross-provider consensus is not promised.
