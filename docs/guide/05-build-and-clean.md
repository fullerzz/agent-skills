# Build a scoped change

Use the matching [playbook](../../skills/poteto-mode/SKILL.md#routing). A bug needs a repro and root cause; a feature needs observable acceptance; a refactor needs a held behavior contract; a performance fix needs a repeatable baseline.

[tdd](../../skills/tdd/SKILL.md) adds cheap meaningful regressions. [no-comments](../../skills/no-comments/SKILL.md) uses a reporting-only comment reviewer; the parent applies only authorized accepted edits. [unslop](../../skills/unslop/SKILL.md) and [technical-writing](../../skills/technical-writing/SKILL.md) keep the explanation readable.
