# No comments

Use an available `comment-sicko` role or an equivalent read-only native reviewer for a scoped report. Follow the [native contract](../z-mode/references/native-hosts.md) for role selection, scoped briefs, and reporting capability gaps.

The reviewer returns locations, proposed removals, refactor targets, evidence, and exceptions. It does not edit code or comments.

The parent checks claims. Protect legal headers, public contracts, justified external constraints, and necessary suppression explanations. Ambiguity calls for how/why investigation, never automatic deletion.

Review requests return findings only. For authorized edits fix root causes before removing correctness suppressions, apply accepted in-scope changes, and verify. Keep unresolved constraints until replacements are proven. Suggestions do not authorize unrelated refactors.

Report accepted/rejected findings, actual edits, proof, and open constraints.
