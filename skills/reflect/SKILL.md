# Reflect

Propose durable lessons from the active conversation. Follow [scoped session evidence](../z-mode/references/history.md); label a digest fallback.

1. Run independent native read-only [judgment](references/judgment-reviewer.md), [tooling](references/tooling-reviewer.md), and [divergent](references/divergent-reviewer.md) lenses using the [native contract](../z-mode/references/native-hosts.md). Queue when needed.
2. Use the [synthesis prompt](references/synthesizer.md). Verify moments, read target skills, prefer existing homes, and distinguish missing guidance from missed invocation.
3. Route enforceable rules to local Backlog mechanisms.
4. Present Accepted / Rejected / Backlog. Apply accepted edits only after approval or an existing explicit request covering them. Filing backlog is a separate requested action.
5. For approved edits use native authoring guidance, validate metadata/links, and run realistic scenarios when behavior changes.

Report proposals or applied edits and remaining gaps. Do not silently write memory, tickets, commits, or PRs.
