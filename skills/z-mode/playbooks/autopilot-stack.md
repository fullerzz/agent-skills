# Autopilot-stack
Run [Autopilot-full](autopilot-full.md) without merging. The operator reviews and lands.
1. Stop at verified. In place of Autopilot-full's merge, stop when each item is verified at its current head, with green CI where published, and hand it off. No merge or auto-merge. After handoff nobody pushes without the operator's go. Name this file in every resume or loop note so the no-merge rule survives.
2. Stack an item only on an item it builds on. Independent items stay independent off trunk. A dependent item's branch, and its PR when publication is authorized, bases on its parent's branch per [Opening a PR](opening-a-pr.md#stacks-and-readiness); each chain's root bases on trunk. Its owner relays verified parent outputs and rebases onto the parent branch, not trunk, recording the parent commit beneath its own commits. Push only under covered publication authority with [Shipping](shipping.md)'s pinned lease.
3. A new parent head restacks the items above it. A child whose `git patch-id` is unchanged keeps its verdict; otherwise re-verify per Autopilot-full step 3. With Herdr, release dependents only after artifact acceptance, not merely a ready agent state.
If interrupted save a handoff. Return each item with its verdict, head, and base in place of what merged, plus excluded or blocked work.
