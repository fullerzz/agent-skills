# Eval
1. Define the behavior under evaluation and 3-6 concrete criteria; hold the rubric out of candidate prompts.
2. Prepare isolated ordinary project directories with only intended variant skills/configuration.
3. Give each candidate the same realistic request without variant/model labels or grading cues. Use native sessions and known supported model settings.
4. Capture each session's actual tool/artifact evidence following the scoped history contract. A self-report does not prove the skill was read.
5. A fresh judge scores sanitized outputs blind to variant/model labels. If no independent judge is available, mark parent-only evaluation.
6. Inspect outputs yourself, reconcile the judge, and record actual identities, failures, and coverage.
Return rubric, receipts, verdict, and recommendation. Do not promote, publish, or start cross-provider orchestration as a side effect.
