# Setup zstack

Inspect the selected host's discovery and report what is installed versus actually loaded. Preview installation collisions before requested installation. This library maintains no parallel model-routing rule.

Default to native inheritance. For a requested model change inspect native configuration and current help/docs, show the exact proposed fields, then preserve unrelated settings. Codex agent TOML may use separate model and model_reasoning_effort fields. Claude agent Markdown uses model: inherit or a verified supported model, with effort separately where supported. Never fabricate effort-suffixed IDs or infer entitlement.

See the [native contract](../z-mode/references/native-hosts.md). Bundled roles are z-agent and comment-sicko. Installer reruns preserve modified agent copies and report collisions. Verify explicit invocation and a delegated read-only investigation in a new session. If delegation is unavailable, report the gap. Inspect the project harness before suggesting create-verification-skill.

For Hermes, inspect the native plugin listing, verify an explicit `skill_view` load of a qualified name such as `zstack:how`, and check the current Hermes hook controls. Do not install Codex/Claude agent files or run another host's controls. Use verified Hermes model configuration for requested changes. Verify explicit activation, resume, disable, and reset; report the compaction session-ID rotation limit from the native contract.
