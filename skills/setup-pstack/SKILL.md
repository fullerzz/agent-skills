# Setup pstack

Inspect the selected host's discovery and report what is installed versus actually loaded. Preview installation collisions before requested installation. This library maintains no parallel model-routing rule.

Default to native inheritance. For a requested model change inspect native configuration and current help/docs, show the exact proposed fields, then preserve unrelated settings. Codex agent TOML may use separate model and model_reasoning_effort fields. Claude agent Markdown uses model: inherit or a verified supported model, with effort separately where supported. Never fabricate effort-suffixed IDs or infer entitlement.

See the [native contract](../poteto-mode/references/native-hosts.md). Bundled roles are poteto-agent and comment-sicko. Installer reruns preserve modified agent copies and report collisions. Verify explicit invocation and a delegated read-only investigation in a new session. If delegation is unavailable, report the gap. Inspect the project harness before suggesting create-verification-skill.
